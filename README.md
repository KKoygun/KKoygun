#### Repositories

**[defect-bridge](https://github.com/KKoygun/defect-bridge)**  
Pipes Allure test failure results into linked Jira defects automatically after every CI run — structured comments, screenshots attached, zero manual defect reporting. Built to solve a real problem from production CI cycles.

**[Playwright-cucumber-ai-framework](https://github.com/KKoygun/Playwright-cucumber-ai-framework)**  
Playwright + TypeScript + Cucumber BDD with three AI agents (Healer, Planner, Generator) on a provider-agnostic adapter — swap Groq, Gemini, Claude, or OpenAI by changing one line. Parallel CI on both GitHub Actions and Azure Pipelines.

**[playwright-api-framework](https://github.com/KKoygun/playwright-api-framework)**  
REST API test framework applying Page Object Model thinking to the HTTP layer — typed client classes, Zod schema validation for contract testing, fixture injection, Allure reporting, parallel CI.
